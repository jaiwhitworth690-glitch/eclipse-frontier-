# Eclipse Frontier

A single launch page brings together two playable versions of the browser action RPG.

## Adventures

- **The Shattered Verge** (shattered-verge.html) preserves the original field test: a forest clearing, a Veil Stalker, and a three-sunshard quest.
- **The Verdant Reach** (expanded-frontier.html) is the larger exploration build: a broad wilderness, leveled creatures, loot, experience, potions, an Arcane Burst, a hidden altar, and the Sunken Archive dungeon with its guardian.

Open index.html through a local HTTP server. The game uses Three.js from jsDelivr, so the first load needs an internet connection. Start it with: python -m http.server 8000. Then visit http://localhost:8000.

Both builds are single-player prototypes. Multiplayer, accounts, saved progression, and backend services are not implemented.
